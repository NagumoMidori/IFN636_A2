# IFN636 Assessment 2 (2.1 & 2.2) Software development, testing and configuration: Details

## Overview

### Task description

To simulate the real-world software development lifecycle by collaboratively designing, developing, and deploying an object-oriented application using advanced OOP concepts, popular design patterns, API Testing, functional testing, CI/CD pipeline, load balancing, version control and team collaboration. The project will also involve a software requirements specification (SRS). The submission template contains a sample for the SRS document, but you do not need to strictly follow it.

Since this is a group project, your group must choose one project from the set of projects previously selected by group members in Assessment 1. The group will work collaboratively on the chosen project for this assessment. Before selecting the project, you must form the group. The groups are available; please navigate to People -> Ass2 Group and enroll yourself in a group. All group members should agree on forming a group. Please discuss with your group members and set clear expectations among the group members. As you are choosing an existing project, you need to extend the project by adding at least two functionalities.

**Submission Template:** [Assessment 2 - Submission Template sem2.docx](https://canvas.qut.edu.au/courses/24596/files/8231908?wrap=1)

The assessment demonstration will be conducted during your tutorial session in Week 13.

### Unit Learning Outcomes assessed

**ULO 1:** Explain the key stages of the software life cycle, the different artefacts associated required to be produced through these and the supportive techniques, languages and tools used.

**ULO 3:** Develop a software implementation and test plans comprising a software application module, its components and application programming interfaces.

**ULO 4:** Configure a software implementation using Cloud systems to meet given load balancing and load testing requirements when it is operated.

**ULO 5:** Apply effective teamwork using ICT professional roles and project work practices.

## What you need to do

You need to complete the following tasks:

- Basic SRS documentation
- Design Pattern and OOP Principles
- API Testing
- Functional Testing
- CI/CD Pipeline
- Load Balancing and Load Testing
- Team Collaboration
- Report

After submitting your Assessment 2, you will need to have a group presentation, which will be conducted during the Review Lecture and Tutorial sessions in Week 13.

Please note that your assessment will not be marked if you do not present during the group presentation. Your presentation performance can impact your final report marking. If you have any questions, please talk to your tutor.
